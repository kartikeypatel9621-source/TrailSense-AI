🌎 About the Project

TrailSense AI is a browser-based outdoor exploration platform designed to turn ordinary walks into interactive real-world adventures.

Instead of keeping users glued to their screens, TrailSense encourages them to explore their surroundings, discover natural patterns, observe wildlife, and complete outdoor missions.

Built using HTML, CSS, and JavaScript, the project focuses on an engaging, responsive interface with an architecture designed for integration with open-weight AI models.

Challenge Theme: Touch Grass 🌱

✨ Features

🧭 AI-Generated Exploration Missions

- Discover nature through interactive missions.
- Explore leaves, wildlife evidence, natural patterns, and outdoor environments.
- Generate new exploration challenges.

📸 Nature Scanner

- Select or upload photographs of natural objects.
- Preview observations directly in the browser.
- Designed for integration with an open-weight vision model for image analysis.

🧠 AI Outdoor Companion

- Ask questions about plants, wildlife, nature, and outdoor exploration.
- Get guidance for observation-based activities.
- Designed for integration with an open-weight language model.

🎙️ Voice Explorer

- Browser-based speech recognition where supported.
- Ask questions using voice instead of typing.

🏆 Gamification System

- Earn experience points (XP).
- Track discoveries and expedition progress.
- Monitor exploration levels and outdoor streaks.
- Save basic progress using browser local storage.

📊 Expedition Report

- View your exploration statistics.
- Track recorded discoveries and accumulated XP.
- Review your outdoor exploration progress.

🧠 Open-Source AI Approach

TrailSense is designed around the principles of open innovation, privacy, and local-first intelligence.

The planned AI architecture allows developers to integrate compatible open-weight models for tasks such as:

- Nature observation assistance
- Outdoor mission generation
- Image understanding
- Nature-related question answering
- Offline AI interaction when supported by the selected model and runtime

Why Open AI?

- Privacy: Supports an architecture where personal observations can remain on the user's device.
- Offline potential: Local inference can reduce dependence on internet connectivity after model setup.
- Model flexibility: Developers can replace or customize models.
- Accessibility: Local inference can reduce recurring API costs.
- Open innovation: The community can experiment with models, prompts, and new features.

«Development status: The current prototype contains frontend demonstration logic and placeholder responses. A real open-weight AI model has not yet been connected. Offline inference and AI-powered image recognition are planned integrations, not currently implemented features.»

🚀 Getting Started

Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (recommended)

Installation

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/trailsense-ai.git

2. Navigate to the project directory

cd trailsense-ai

3. Open the project in VS Code

code .

4. Run the application

Open "index.html" directly in your browser, or use the Live Server extension in VS Code.

No build process or package installation is required for the current frontend prototype.
